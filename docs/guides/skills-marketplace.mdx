## Overview

The **Skills Marketplace** provides a centralized hub for discovering and installing pre-built agent capabilities. Skills extend your agents with specialized functionality without requiring custom code development.

  <Card title="Multi-Source" icon="layer-group">
    Access skills from Anthropic, custom registries, and OCI
  </Card>
</CardGroup>

### What are Skills?

Skills are modular, reusable components that provide agents with specific capabilities. Each skill is defined using a `SKILL.md` file with YAML frontmatter that describes:

- **Skill metadata** - Name, version, author, description
- **Capabilities** - What the skill can do
- **Dependencies** - Required packages and models
- **Instructions** - How to use the skill effectively

### Skill Types

| Type | Description | Example |
|------|-------------|---------|
| **Tool Skills** | Provide new MCP tools to agents | Web scraping, API integration |
| **Prompt Skills** | Enhance agent prompts with specialized knowledge | Legal reasoning, medical diagnosis |
| **Resource Skills** | Add data sources and knowledge bases | Industry regulations, code patterns |

### Benefits of the Marketplace Model

- **Rapid Development** - Build agents faster with pre-built capabilities
- **Quality Assurance** - Trusted skills from verified sources
- **Community Contributions** - Share and discover best practices
- **Version Control** - Track skill versions and updates
- **Secure Sandboxing** - Skills run in isolated environments

## Installing Skills

### One-Click Installation

Installing skills is simple and fast:

<Steps>
  <Step title="Find the Skill">
    Search or browse to locate the skill you need.
  </Step>
  <Step title="Review Details">
    Check skill description, dependencies, and ratings.
  </Step>
  <Step title="Click Install">
    Click the **"Install"** button on the skill card.
  </Step>
  <Step title="Configure (Optional)">
    Some skills require configuration (API keys, settings). Provide these if prompted.
  </Step>
  <Step title="Confirm Installation">
    Review the installation summary and confirm.
  </Step>
</Steps>

The installer will:
- Download skill files from the marketplace
- Install Python dependencies using `uv`
- Validate skill integrity
- Enable the skill for your agents

### User-Level vs Organization-Level Installation

Skills can be installed at different scopes:

| Scope | Access | Use Case |
|-------|--------|----------|
| **User-Level** | Only you | Personal skills for individual workflows |
| **Organization-Level** | All org members | Shared skills for team collaboration |
| **Project-Level** | Project members | Skills scoped to specific projects |

**Installation Scopes**:

```bash
# Install for yourself only (default)
POST /api/v1/admin/marketplaces/{marketplace}/skills/{skill}/install
{
  "scope": "user"
}

# Install for entire organization (requires admin)
POST /api/v1/admin/marketplaces/{marketplace}/skills/{skill}/install
{
  "scope": "organization"
}

# Install for a specific project
POST /api/v1/admin/marketplaces/{marketplace}/skills/{skill}/install
{
  "scope": "project",
  "project_id": "proj_abc123"
}
```

### Permission Requirements

Installation permissions vary by scope:

| Operation | Required Permission |
|-----------|-------------------|
| User-level install | `authenticated` |
| Organization install | `admin` persona |
| Project install | `editor` on project |
| Trusted skill install | No approval needed |
| Untrusted skill install | `admin` approval required |

<Warning>
Skills from untrusted marketplaces require admin approval before they can be used in production workflows.
</Warning>

Control which skills are active for your agents:

  <Accordion title="Enable a Skill" icon="toggle-on">

### Uninstall Skills

Remove skills you no longer need:

<Steps>
  <Step title="Navigate to Installed Skills">
    Go to **Skills > Installed Skills** in the Studio.
  </Step>
  <Step title="Select Skill">
    Click the skill you want to remove.
  </Step>
  <Step title="Uninstall">
    Click **"Uninstall"** and confirm the action.
  </Step>
  <Step title="Cleanup">
    The system will remove skill files and clean up dependencies.
  </Step>
</Steps>

**API Uninstall**:

```bash
DELETE /api/v1/admin/marketplaces/{marketplace}/skills/{skill_name}
```

<Warning>
Uninstalling a skill that's in use by active agents will cause those agents to fail until the skill is reinstalled or workflows are updated.
</Warning>

### Auto-Update Configuration

Configure automatic skill updates to keep skills current:

| Setting | Description | Default |
|---------|-------------|---------|
| **Auto-Update Enabled** | Automatically apply skill updates | `false` |
| **Update Channel** | Which updates to apply (`stable`, `beta`, `all`) | `stable` |
| **Update Schedule** | When to check for updates | Daily at 2 AM UTC |
| **Require Approval** | Admin approval for major version updates | `true` |

**Configure Auto-Updates**:

<Tabs>
  <Tab title="Environment Variables">
    ```bash
    # Enable auto-updates
    FF_ENABLE_SKILL_AUTO_UPDATE=true

    # Set update check interval (seconds)
    SKILL_AUTO_UPDATE_INTERVAL=86400  # 24 hours

    # Require approval for major versions
    SKILL_AUTO_UPDATE_REQUIRE_APPROVAL=true
    ```
  </Tab>
  <Tab title="API">
    ```bash
    # Configure auto-update settings
    PUT /api/v1/admin/skills/auto-update/config
    {
      "enabled": true,
      "channel": "stable",
      "schedule": "0 2 * * *",  # Cron expression
      "require_approval": true
    }
    ```
  </Tab>
</Tabs>

**Check for Updates Manually**:

```bash
# Check for available updates
GET /api/v1/admin/skills/updates

# Response
{
  "updates": [
    {
      "skill_name": "web-research",
      "current_version": "1.2.0",
      "new_version": "1.3.0",
      "marketplace": "anthropic",
      "changelog": "Added support for PDF extraction"
    }
  ],
  "count": 1
}
```

**Apply Updates**:

```bash
# Apply all available updates
POST /api/v1/admin/skills/updates/apply

# Response
{
  "applied": [
    {
      "skill_name": "web-research",

      "success": true
```

## Feature Flags

Control Skills Marketplace functionality using feature flags:

### enable_skills_marketplace

**Enable or disable the entire Skills Marketplace integration.**

```bash
# Enable marketplace (default)
FF_ENABLE_SKILLS_MARKETPLACE=true

# Disable marketplace
FF_ENABLE_SKILLS_MARKETPLACE=false
```

**Impact**:
- When `true`: Skills marketplace UI and API endpoints are available
- When `false`: All marketplace features are disabled; only manually installed skills work

**Use Case**: Disable for air-gapped deployments or when using only internal skills.

### enable_skills_system

**Enable or disable the SKILL.md-based skills system.**

```bash
# Enable skills system (default)
FF_ENABLE_SKILLS_SYSTEM=true

# Disable skills system
FF_ENABLE_SKILLS_SYSTEM=false
```

**Impact**:
- When `true`: Agents can use skills defined in SKILL.md files
- When `false`: Skills are ignored; agents use only built-in capabilities

**Use Case**: Disable for deployments that don't need skill extensibility.

### skills_cache_ttl_seconds

**Control how long marketplace data is cached locally.**

This is configured through the `MarketplaceClient` initialization:

```python
from mcp_server_langgraph.skills.marketplace import MarketplaceClient

# Default cache TTL (1 hour)
client = MarketplaceClient()

# Custom cache TTL (15 minutes)
client = MarketplaceClient(cache_ttl_seconds=900)

# Disable caching (always fetch fresh data)
client = MarketplaceClient(cache_ttl_seconds=0)
```

**Impact**:
- Higher values reduce API calls but may show stale skill listings
- Lower values ensure fresh data but increase latency
- `0` disables caching (not recommended for production)

**Recommended Values**:
- **Development**: `300` (5 minutes) - See changes quickly
- **Production**: `3600` (1 hour) - Balance freshness and performance
- **Air-gapped**: `86400` (24 hours) - Minimize external calls

## Marketplace Types

The Skills Marketplace supports multiple source types:

### GitHub Marketplaces

**Default**: Anthropic's official skills repository

```bash
# Configuration
{
  "name": "anthropic",
  "uri": "https://github.com/anthropics/skills",
  "type": "github"
}
```

**Structure**:
```
skills/
├── web-research/
│   └── SKILL.md
├── code-review/
│   └── SKILL.md
└── compliance-checker/
    └── SKILL.md
```

### OCI Registries

**Use OCI (Open Container Initiative) registries for enterprise skill distribution.**

```bash
# Configuration
{
  "name": "company-oci",
  "uri": "oci://ghcr.io/company/skills",
  "type": "oci"
}
```

**Benefits**:
- **Version control** - Immutable skill images with SHA digests
- **Private access** - Authentication and access control
- **Caching** - Leverage existing container infrastructure

### Custom Registries

**Build your own skill registry with a REST API.**

```bash
# Configuration
{
  "name": "custom-registry",
  "uri": "https://skills-api.company.com/v1",
  "type": "registry"
}
```

**Required API Endpoints**:
- `GET /skills` - List all skills
- `GET /skills/{name}` - Get skill details

**Example Response**:
```json
{
  "skills": [
    {
      "name": "internal-tool",
      "version": "2.1.0",
      "description": "Company-specific automation tool",
      "type": "registry"
    }
  ]
}
```

## Security Considerations

### Trusted vs Untrusted Marketplaces

| Marketplace | Trust Level | Approval Required |
|-------------|-------------|-------------------|
| **Anthropic Official** | Trusted | No |
| **Organization Internal** | Trusted (configurable) | Configurable |
| **Third-Party** | Untrusted | Yes |

<Warning>
Only install skills from marketplaces you trust. Skills have access to:
- Agent prompts and responses
- MCP tool capabilities
- Environment configuration
- Session data
</Warning>

### Sandboxed Execution

All skills run in isolated sandboxes with:

- **Restricted filesystem access** - Skills can't read arbitrary files
- **Network isolation** - Controlled external access
- **Resource limits** - CPU, memory, and execution time limits
- **API boundaries** - Skills communicate only through defined interfaces

### Approval Workflows

For untrusted skills, an admin approval workflow is enforced:

<Steps>
  <Step title="User Requests Skill">
    User attempts to install skill from untrusted marketplace.
  </Step>
  <Step title="Request Queued">
    Installation request is queued for admin review.
  </Step>
  <Step title="Admin Reviews">
    Admin reviews skill source, dependencies, and permissions.
  </Step>
  <Step title="Approve or Reject">
    Admin approves or rejects the installation.
  </Step>
  <Step title="Installation Proceeds">
    If approved, skill is installed automatically.
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Marketplace won't load" icon="cloud-slash">
    **Possible Causes**:
    1. `FF_ENABLE_SKILLS_MARKETPLACE=false` in environment
    2. Network connectivity issues
    3. Marketplace URL is incorrect

    **Solutions**:
    1. Check feature flag: `FF_ENABLE_SKILLS_MARKETPLACE=true`
    2. Verify network access to marketplace URI
    3. Test marketplace URL manually: `curl https://api.github.com/repos/anthropics/skills/contents/skills`
  </Accordion>

  <Accordion title="Skill installation fails" icon="circle-exclamation">
    **Possible Causes**:
    1. Missing dependencies
    2. Permission issues
    3. Insufficient disk space
    4. Network timeout

    **Solutions**:
    1. Check dependency errors in logs
    2. Verify you have write access to skill install path
    3. Ensure adequate disk space (`df -h`)
    4. Increase timeout: `SKILL_INSTALL_TIMEOUT_SECONDS=300`
  </Accordion>

  <Accordion title="Auto-updates not working" icon="arrows-rotate">
    **Possible Causes**:
    1. Auto-update disabled
    2. Scheduler not running
    3. Insufficient permissions

    **Solutions**:
    1. Enable: `FF_ENABLE_SKILL_AUTO_UPDATE=true`
    2. Check scheduler status: `GET /api/v1/admin/skills/auto-update/status`
    3. Verify admin permissions for update operations
  </Accordion>

  <Accordion title="Custom marketplace not syncing" icon="server">
    **Possible Causes**:
    1. Invalid marketplace URI
    2. Authentication required but not provided
    3. API endpoint format mismatch

    **Solutions**:
    1. Validate URI format (must be HTTPS)
    2. Add authentication headers if needed
    3. Ensure API returns expected format (see Custom Registries section)
  </Accordion>
</AccordionGroup>

## Best Practices

### Skill Selection

<Check>
**DO**:
- Review skill ratings and reviews before installing
- Test skills in development before production use
- Keep skills updated to latest stable versions
- Monitor skill usage and performance
- Remove unused skills to reduce attack surface
</Check>

<Warning>
**DON'T**:
- Install skills from untrusted sources without review
- Grant organization-wide access to untested skills
- Ignore dependency conflicts
- Disable security features for convenience
</Warning>

### Performance Optimization

1. **Use caching wisely** - Balance freshness vs API load
2. **Enable auto-updates during off-hours** - Minimize disruption
3. **Limit concurrent installations** - Prevent resource exhaustion
4. **Monitor disk usage** - Clean up old skill versions

### Security Hygiene

1. **Audit installed skills regularly** - Review what's installed and why
2. **Enable approval workflows** - Require review for untrusted skills
3. **Use organization-level installs sparingly** - Limit blast radius
4. **Monitor skill activity** - Check logs for unexpected behavior

## Example: Installing the Web Research Skill

Here's a complete example of discovering, installing, and using a skill:

<Steps>
  <Step title="Discover the Skill">
    ```bash
    # Search for web research skills
    GET /api/v1/admin/marketplaces/anthropic/skills?search=web+research

    # Review skill details
    GET /api/v1/admin/marketplaces/anthropic/skills/web-research
    ```

  <Step title="Install the Skill">
    ```bash
    # Install at user level
    POST /api/v1/admin/marketplaces/anthropic/skills/web-research/install
    ```

  <Step title="Enable in Agent">

    1. Open an agent configuration

  <Step title="Use the Skill">
    Ask your agent:
    ```
    "Research the latest developments in quantum computing
    and summarize the top 5 breakthroughs from 2025."
    ```

    The agent will use the web-research skill to:
    - Search for relevant articles
    - Extract key information
    - Summarize findings
  </Step>
</Steps>
