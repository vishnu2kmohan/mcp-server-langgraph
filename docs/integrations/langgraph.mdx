# LangGraph Integration

Build sophisticated agent workflows with LangGraph's graph-based execution model.

## Overview

MCP Server LangGraph provides native LangGraph integration with:

| Feature | Description |
|---------|-------------|
| **State Management** | Persistent agent state across turns |
| **Graph Execution** | Visual workflow definition |
| **Checkpointing** | Save/resume execution points |
| **HITL Patterns** | Human-in-the-loop approvals |
| **Multi-Agent** | Orchestrate multiple agents |

---

## Quick Start

### Basic Agent Graph

```python
from langgraph.graph import StateGraph, END
from langgraph.prebuilt import create_react_agent
from langchain_openai import ChatOpenAI

# Define state
class AgentState(TypedDict):
    messages: list
    next_step: str

# Create graph
graph = StateGraph(AgentState)

# Add nodes
graph.add_node("agent", agent_node)
graph.add_node("tools", tool_node)

# Add edges
graph.add_edge("agent", "tools")
graph.add_conditional_edges(
    "tools",
    should_continue,
    {"continue": "agent", "end": END}
)

# Compile
app = graph.compile()
```

### With MCP Tools

```python
from mcp_server_langgraph.tools import get_mcp_tools
from langgraph.prebuilt import create_react_agent

# Get MCP tools
tools = await get_mcp_tools()

# Create agent with MCP tools
agent = create_react_agent(
    model=ChatOpenAI(model="gpt-4"),
    tools=tools
)

# Run
result = await agent.ainvoke({
    "messages": [{"role": "user", "content": "Search for Python tutorials"}]
})
```

## State Persistence

### Redis Checkpointing

```python
from langgraph.checkpoint.redis import RedisSaver

# Configure Redis checkpointer
checkpointer = RedisSaver.from_url("redis://localhost:6379")

# Compile with checkpointing
app = graph.compile(checkpointer=checkpointer)

# Run with thread ID for persistence
config = {"configurable": {"thread_id": "session-123"}}
result = await app.ainvoke(input, config)
```

### PostgreSQL Checkpointing

```python
from langgraph.checkpoint.postgres import PostgresSaver

checkpointer = PostgresSaver.from_conn_string(
    "postgresql://user:pass@localhost/db"
)

app = graph.compile(checkpointer=checkpointer)
```

## Human-in-the-Loop

### Interrupt for Approval

```python
from langgraph.graph import StateGraph

graph = StateGraph(AgentState)

# Add interrupt before sensitive operations
graph.add_node("check_approval", check_approval_node)
graph.add_node("execute", execute_node)

# Interrupt requires human approval
graph.add_edge("check_approval", "execute", interrupt_before=["execute"])
```

### Resume After Approval

```python
# Get pending approval
state = await app.aget_state(config)
if state.next == ["execute"]:
    # Human approves
    await app.ainvoke(None, config)  # Resume execution
```

## Multi-Agent Patterns

### Supervisor Pattern

```python
from langgraph.graph import StateGraph

class SupervisorState(TypedDict):
    messages: list
    next_agent: str

def supervisor_node(state):
    # Decide which agent to call
    return {"next_agent": decide_next_agent(state)}

graph = StateGraph(SupervisorState)
graph.add_node("supervisor", supervisor_node)
graph.add_node("researcher", researcher_agent)
graph.add_node("writer", writer_agent)

graph.add_conditional_edges(
    "supervisor",
    lambda s: s["next_agent"],
    {"researcher": "researcher", "writer": "writer", "end": END}
)
```

### Handoff Pattern

```python
from mcp_server_langgraph.orchestration import create_handoff_graph

graph = create_handoff_graph(
    agents={
        "researcher": researcher_agent,
        "writer": writer_agent,
        "reviewer": reviewer_agent
    },
    handoff_order=["researcher", "writer", "reviewer"]
)
```
